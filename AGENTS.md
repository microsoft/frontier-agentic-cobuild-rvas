# Repository instructions

## Writing

Before drafting, editing, or returning repository prose, invoke
`humanize-content`. This includes documentation, Markdown, and user-facing
explanations. Do not apply it to files under `plugins/` or to `AGENTS.md`.

Use [TONE-OF-VOICE.md](TONE-OF-VOICE.md) unless the user requests another voice.
Write for competent engineers: lead with the point, use concrete verbs, name the
actor when it matters, and explain complexity only when the reader needs it.
Preserve technical facts, Microsoft product names, dates, citations, and
governance terms.

## Relevance and source of truth

Apply diminishing returns: keep material only when it changes the reader's
understanding, decision, or next action. Remove repetition, generic benefits,
and steps or deliverables that do not help the reader act.
