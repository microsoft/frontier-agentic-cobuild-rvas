# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Customer technical teams and their advisers building a new AI application or
adding an AI capability to an existing system. Delivery teams use the same
architecture package to agree scope and acceptance.

## Product Purpose

Agentic Co-build provides an installable agent plugin and supporting skill setup.
The user works in their own repository. AI Agent Creator owns discovery and
architecture approval; implementation starts in a separate session.

## Positioning

Lead with **build or evolve your own AI application**. The primary action opens
the setup guide. Idea Forge is optional preparation for users who need a bounded,
evidence-backed idea first.

## Operating Context

Support GitHub Copilot CLI and VS Code Copilot. Distribute the plugin from
`microsoft/frontier-agentic-cobuild-rvas`. Install third-party supporting skills
at project scope from the explicit inventory in `scripts/agentic-skills.json`.
Keep the tooling repository separate from the user's application workspace.

## Capabilities and Constraints

Bundle AI Agent Creator, Cloud Architecture Diagram, and Idea Forge. Supply
documentation-only Microsoft Learn MCP. Preserve discovery confirmation and
complete-package approval, including explicit diagram-review exceptions.

Setup preserves existing code, instructions, MCP settings, and skills. It creates
no Git repository, cloud resources, or system-tool installation. Architecture
approval never starts implementation or deployment.

## Brand Commitments

Preserve the Agentic Co-build name, RVAP/RVAS logos, existing blue/navy palette,
Outfit/Inter fonts, and light reading surfaces. Favor a direct path to setup over
a catalog. Use plain, outcome-first language.

## Evidence on Hand

The bundled skills, their contracts and local diagram assets, the upstream skill
inventory, the setup script, and validation results. Do not invent customer
evidence, readiness claims, or guarantees about model behavior.

## Product Principles

Start with the customer's outcome and existing environment. Keep approval gates
explicit. Validate delivery against the specification, and report blocked work
with its owner. Third-party guidance and asset terms remain identifiable.

## Accessibility & Inclusion

Provide readable command blocks, visible keyboard focus, responsive navigation,
and a guide usable without Bash through equivalent manual commands.
