in `plugins/agentic-cobuild/skills/cloud-architecture-diagram/assets/`.
They illustrate product examples in the application-family documentation.

Microsoft permits these icons in architecture diagrams, training materials, and
documentation. The repository's MIT license does not cover this artwork.
Keep each icon unchanged and place the product name beside it.
See the [official icon terms](https://learn.microsoft.com/azure/architecture/icons/)
and [Power Platform icon terms](https://learn.microsoft.com/power-platform/guidance/icons)
and the [bundled attribution](../../../../plugins/agentic-cobuild/skills/cloud-architecture-diagram/references/REFERENCE.md#source-and-asset-terms).

The adjacent `document-analysis.svg` and `code.svg` are first-party illustrations,
not Microsoft product logos. Voice Live uses the Azure Speech icon because it is
a capability of that service.
