One journey, in your workspace.

The plugin supplies the design workflow. Your repository holds the application and its architecture records.

  1. Prepare the repository

    Install the plugin and selected upstream skills. Reuse the existing application's conventions when there is one.

  2. Define and approve

    AI Agent Creator interviews you, proposes the architecture, and produces the complete package for review.

  3. Build in a new session

    Hand the approved files to the implementation agent. Validate against the specification and resolve review findings.

Approval stays explicit. Setup and architecture design do not provision resources or change your application code.
