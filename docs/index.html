The experience

How it works.

Use the playbooks to co-build the agreed part of the customer's solution. Slides support design discussions; modules guide the build.

01
Agree the scope

Define the customer outcome and acceptance criteria. Use Idea Forge if the opportunity is still unclear.

02
Map the parts to modules

Run Use-Case Mapper to map each part to modules across tracks. It shows what to adapt and what the kit doesn't cover.

03
Build together

Work through the design decisions and adapt the building blocks for the agreed parts. Respect module prerequisites and use the approved environment.

04
Check the result

Check the result against the agreed acceptance criteria. Assign an owner to any remaining work.

Scope each engagement. The kit can support a pilot or a longer co-build. Guided module times exclude customer-specific engineering. Production readiness needs acceptance in the customer's environment. Deploying an accelerator doesn't prove it.

Deliver in the customer's tenant. Reuse approved resources and connect the actual sources and user channel. Reference code and synthetic checks support the build; they do not replace tenant acceptance.
